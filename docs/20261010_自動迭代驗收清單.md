> 每一項都只在 **spine 副本**上驗證過。這份清單告訴你：裝上之後在真實使用中看什麼、怎樣算有用。

## 0. 裝上

1. 從選單列「結束」Repo Context App（或 ⌘Q）。**會結束 App 裡正在跑的會話**，先收好。
2. `bash scripts/install-app.sh --dry-run`：先看會做什麼。
3. `bash scripts/install-app.sh`：build → 備份舊版到 `~/.cache/repo-context/app-backups/` → 裝到 /Applications → 刪掉 build 目錄那份。
4. 更新 agent 看的 skill：`ctx setup --claude`（已裝過也要重跑，skill 才會有新能力那一段；看到「已掛」會略過的是 MCP 與 hooks，skill 會覆寫——先 `--dry-run` 確認）。
5. 開一個**新的** Claude Code 會話（舊會話的 `ctx mcp` 還是舊的）。

回退：把 `~/.cache/repo-context/app-backups/<時間>/Repo Context.app` 用 `ditto` 放回 /Applications。
