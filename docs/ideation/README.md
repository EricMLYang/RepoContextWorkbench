# ideation：PM 構想盤點（每輪累積）

> 由 skill `pm-ideation`（`.claude/skills/pm-ideation/SKILL.md`）維護。
> 每一輪：讀現況 → 量非功能基準 → 從對標清單延伸搜尋 → 產出功能／非功能清單與排序 → 落檔。
> 取捨準則（AGENTS.md）：**脈絡**＝更快拿到對的脈絡｜**留痕**＝判斷有留痕｜**同介面**＝人和 agent 走同一個介面。

## 檔案

| 檔 | 內容 | 更新規則 |
|---|---|---|
| `backlog.md` | 構想池：功能 F-xx／非功能 N-xx | ID 永不重編；只改狀態，放棄要寫理由 |
| `benchmarks.md` | 對標清單＋搜尋線索 | 新對標加列；查過更新「最後查證」；每輪寫新的「下一輪查詢」 |
| `baseline.md` | 非功能量測基準 | 每輪加一欄，看趨勢 |
| `rounds/` | 每輪的完整分析 | `YYYYMMDD_Rnn_主題.md`，用 `_template_round.md` |

查證標記：✅ 讀過官方原文｜🔗 只看到搜尋結果｜💭 推論。
