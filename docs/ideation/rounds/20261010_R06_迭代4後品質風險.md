## 2. 對標（2 條）→ F-33 做法
「相關 repo 建議」要用四種**可解釋**的訊號，每個建議都附理由，人確認後才 relate：
1. **直接提到**：A 的文件提到 B 的 repo id 或路徑，但兩者之間還沒有關係（Obsidian「未連結提及」）。
2. **引用紀錄**：A 的會話 read_from 過 B（cites.jsonl）。
3. **一起改**：同一段時間兩個 repo 都有 commit（co-change mining：版本歷史裡藏著靜態分析看不到的關係）。
4. **共同主題詞**：沿用反芻的濾網（像一個詞、不是一般用語）。
